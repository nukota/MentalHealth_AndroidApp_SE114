# Mental Health Android App

A mobile application that empowers users to improve and maintain their mental well-being through daily journaling, mood tracking, personalized reminders, and motivational content. This app is designed with a focus on modern Android development best practices, built using **Kotlin**, **Jetpack Compose**, and **Firebase** services.
> 🎓 This project was developed as the **final assignment for the SE114 - Introduction to Mobile Application Development** course at UIT. It was a collaborative effort by our team to demonstrate practical application of mobile development principles and cloud integration.

## 🧰 Tech Stack

### 💻 Languages & Frameworks
- [Kotlin](https://kotlinlang.org/) — modern, expressive, safe
- [Jetpack Compose](https://developer.android.com/jetpack/compose) — declarative UI toolkit
- MVVM architecture using ViewModel, LiveData, and StateFlow

### ☁️ Firebase Integration
- **Firebase Authentication** — Email/Password, Google Sign-in
- **Firebase Firestore** — Cloud NoSQL database for structured journaling data
- **Firebase Realtime Database** — Low-latency mood tracking sync
- **Firebase Storage** — (Optional) For storing media content or journal images


- 💡 Motivation
Mental health is an essential aspect of a balanced life. This app was born from a desire to build something meaningful — a tool to help people reflect, reset, and grow emotionally. I also used this project to challenge myself with modern mobile development patterns and Firebase backend integration.

📚 What I Learned
Applying Jetpack Compose for reactive, declarative UI development
Designing scalable app architecture with ViewModel, StateFlow, and repository pattern
Integrating multiple Firebase services cohesively
Managing local and cloud-based data syncing
Building production-level navigation and UI state management
